Species Distributions

Distribution records for a scientific name across every ChecklistBank dataset. It keeps external datasets and the newest release of each project (for COL, its newest XRelease). It leaves out projects, older releases and the legacy COL Annual Checklists.

How to get the distribution data from the API yourself

Everything on this page comes from public, keyless JSON APIs that allow cross-origin requests. The examples use Pterois miles against the production API https://api.checklistbank.org; jq is only used to trim the output. API docs: api.checklistbank.org.

1. Find every dataset with the name

The cross dataset search is the dataset independent /nameusage/search. type=EXACT with content=SCIENTIFIC_NAME matches the full name only. Page with offset; limit is at most 1000.

curl -s 'https://api.checklistbank.org/nameusage/search?q=Pterois%20miles&content=SCIENTIFIC_NAME&type=EXACT&limit=1000' \
  | jq '.total, (.result[].usage | {datasetKey, id, status, accepted: .accepted.id, nidx: .name.namesIndexId})'

Just the dataset keys: limit=0&facet=datasetKey&facetLimit=1000, then read .facets.datasetKey[].value. For GRIIS only, add publisherKey=cdef28b1-db4e-4c58-aa71-3c5238c2d0b5 (ISSG).

2. Decide which datasets to use

curl -s 'https://api.checklistbank.org/dataset/2011/simple' | jq '{key, origin, sourceKey, alias, title, version}'

origin is external, project, release or xrelease; sourceKey is a release's project. This page keeps every external dataset and, for each project, only the release with the highest key among the hits, preferring xrelease. It drops projects and the legacy COL Annual Checklists (external datasets with alias COL00–COL19). /dataset/3LXR/simple resolves the newest COL XRelease if you need it directly.

3. Get the distribution records

Distributions hang off the accepted taxon. Use the usage id when its status is accepted, otherwise accepted.id. URL-encode the id; many contain : or /.

curl -s 'https://api.checklistbank.org/dataset/2011/taxon/urn%3Alsid%3Amarinespecies.org%3Ataxname%3A218077/distribution' \
  | jq '.[] | {area, establishmentMeans, degreeOfEstablishment, threatStatus}'

Each record has an area with gazetteer, id, name and globalId (gazetteer:id). gazetteer: "text" means a free-text area with no shape. The others (iso, tdwg, mrgid, fao, …) are gazetteer areas.

Shortcut, undocumented: /nameusage/distribution?nidx={namesIndexId}&limit=1000 returns the distributions of all usages with that names-index id across all datasets in one call, including projects and every release. You then have to filter by datasetKey yourself.

4. Get the area shapes

curl -s 'https://api.checklistbank.org/vocab/area/mrgid:7963.geojson' | jq '.properties'
# or by content negotiation
curl -s -H 'Accept: application/geo+json' 'https://api.checklistbank.org/vocab/area/iso:CY' | jq '.properties.name'

Returns one GeoJSON Feature; 404 means the gazetteer has no shape for that id. /vocab/area/mrgid:7963 as plain JSON gives the area's metadata.

5. GBIF occurrences

GBIF indexes occurrences against the Catalogue of Life as checklist 7ddf754f-d193-4cc9-b351-99906754a03b, keyed by COL taxon ids. Look up the COL id in the newest XRelease, then use it as GBIF taxonKey:

curl -s 'https://api.checklistbank.org/dataset/3LXR/nameusage/search?q=Pterois%20miles&content=SCIENTIFIC_NAME&type=EXACT' \
  | jq '.result[].usage | {id, status, accepted: .accepted.id}'     # → 4PWV4

curl -s 'https://api.gbif.org/v1/occurrence/search?checklistKey=7ddf754f-d193-4cc9-b351-99906754a03b&taxonKey=4PWV4&hasCoordinate=true&hasGeospatialIssue=false&occurrenceStatus=PRESENT&limit=0' \
  | jq .count

The map layer uses GBIF's density tiles, as on catalogueoflife.org:

https://api.gbif.org/v2/map/occurrence/density/{z}/{x}/{y}@1x.png?srs=EPSG%3A3857&style=iNaturalist.poly&bin=hex&hexPerTile=64&hasCoordinate=true&hasGeospatialIssue=false&occurrenceStatus=PRESENT&checklistKey=7ddf754f-d193-4cc9-b351-99906754a03b&taxonKey=4PWV4

All in one script

distributions.py does steps 1–4 with the Python standard library only and writes the records plus a GeoJSON FeatureCollection of the areas:

curl -sO https://raw.githubusercontent.com/mdoering/clb-distributions/main/distributions.py
python3 distributions.py "Pterois miles" --griis > distributions.json
